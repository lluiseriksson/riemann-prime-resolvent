# References and novelty boundary

Primary background includes Riemann's memoir, standard texts on the zeta function, classical Stieltjes and moment theory, and current work on prime-built spectral models.

The repository does not claim that moment criteria for RH, Stieltjes transforms, normal-family arguments or real-zero mechanisms are new. The potentially valuable contribution is a transparent integration of these components with a concrete operator error budget, reproducible certificates and formal verification.

Before any novelty claim, update the source audit with exact theorem-level comparisons and obtain specialist review.
