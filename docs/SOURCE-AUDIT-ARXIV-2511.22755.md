# Source audit: prime-built spectral model

The cited source constructs prime-dependent finite-dimensional/self-adjoint models and proves model-side real-zero and substrip convergence statements under stated hypotheses. Its own discussion identifies unresolved tasks concerning the lowest state's simplicity/evenness and the strength of approximation needed to transfer the model behavior to the true state.

This repository therefore treats the following as open:

- uniform simplicity/evenness for the relevant lowest state;
- quantitative state alignment;
- transfer to the resolvent observable with correct domains and traces;
- a non-circular interval convergence theorem.

Any future use must cite exact theorem/equation numbers and preserve transform conventions. A source's conditional model theorem is not a proof of the missing construction-side interface.
