# Documentation plan

The documentation site is the manuscript. Changes to mathematical claims must update, in one pull request:

- the relevant page under `docs/programme/`;
- `docs/MATHEMATICAL-STATUS.md`;
- `docs/THEOREM-LEDGER.md` when a Lean declaration changes status;
- the interface contract when a shared definition changes;
- tests, figures and source references;
- the changelog.

The project does not build, upload or version a separate paper PDF.
