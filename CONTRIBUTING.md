# Contributing

Contributions are welcome in small, reviewable increments.

1. Open an issue naming one theorem-ledger item.
2. Keep conditional assumptions explicit.
3. Do not add project axioms or placeholders.
4. Add a minimal test or `#print axioms` line.
5. Update the theorem ledger and verification ledger.
6. Cite primary sources with exact theorem/section/page information.

Changes that claim progress on RH require unusually strong review and must not
be merged solely on numerical evidence.
